Draw.io XML (из Visio)
Импорт блок-схемы из app.diagrams.net. Для Visio (.vsdx): откройте в Draw.io → File → Save As → XML.
Автосохранение
Все изменения автоматически сохраняются в браузере. Данные доступны при следующем открытии.
Формат CSV: колонки id, title, intent, type, section, next_default, next_yes, next_no, text_ru, text_uz. Обязательна только id. Скачайте шаблон чтобы увидеть пример.

Импорт из Visio:
1. Откройте бесплатный app.diagrams.net → File → Open from → Device → выберите ваш .vsdx файл
2. После открытия: File → Save As → выберите формат .xml (NOT .drawio compressed)
3. Загрузите этот .xml выше — все блоки и связи импортируются автоматически
4. Тексты ru/uz придётся заполнить вручную или через AI (✨ кнопки)

Как получить PDF:
1. Нажмите «Полный PDF» или «PDF только схемы»
2. В новом окне: Ctrl+P (или ⌘+P) → «Сохранить как PDF»
3. Для схемы выбирайте «Альбомная» ориентация

Draw.io экспорт: XML-файл можно открыть на app.diagrams.net для ручной доработки схемы.
